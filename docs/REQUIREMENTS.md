# 요구사항 명세 초안

- 문서 상태: **초안 (v0.1)**
- 표기: `[P0]` 없으면 출시 불가 / `[P1]` 1.0에 포함 / `[P2]` 이후 버전

## 1. 사용자 시나리오

1. **기본**: 사용자가 YouTube URL을 복사 → 앱이 클립보드를 감지해 자동 입력 → 화질 `4K` 선택 → 다운로드 → 지정 폴더에 `제목.mp4` 생성
2. **일괄**: 재생목록 URL 입력 → 항목 리스트 표시 → 체크박스로 선별 → 큐에 추가 → 3개씩 순차 처리
3. **오디오만**: 강의/음악 영상에서 m4a만 추출
4. **중단 복구**: 다운로드 도중 앱 종료 → 재실행 시 "이어받기" 제안

## 2. 기능 요구사항

### 2.1 입력
- `[P0]` 단일 영상 URL(youtube.com/watch, youtu.be, shorts)
- `[P0]` 잘못된 URL/비공개/삭제된 영상에 대한 명확한 오류 메시지
- `[P1]` 재생목록 URL, 채널 URL
- `[P1]` 클립보드 자동 감지
- `[P2]` 여러 URL 텍스트 파일 임포트

### 2.2 포맷/화질
- `[P0]` 사용 가능한 화질 목록 표시(해상도, fps, 코덱, 예상 용량)
- `[P0]` 목표 화질 선택: 최고화질 / 2160p / 1440p / 1080p / 720p
- `[P0]` 목표 화질이 없으면 **그 아래 최고 화질로 자동 대체**하고 사용자에게 고지
- `[P1]` 코덱 선호 설정(VP9 우선 / AV1 우선 / 호환성 우선)
- `[P1]` HDR 스트림 표시 및 선택
- `[P2]` 용량 상한 지정("2GB 이하 중 최고 화질")

### 2.3 다운로드
- `[P0]` 진행률: 퍼센트, 다운로드 속도, 남은 시간, 현재 단계(영상/음성/병합)
- `[P0]` 취소
- `[P0]` 이어받기(`.part` 기반)
- `[P0]` 동시 다운로드 개수 설정(기본 3)
- `[P1]` 일시정지/재개
- `[P1]` 병렬 fragment 다운로드 개수 설정
- `[P2]` 속도 제한 설정, 예약 다운로드

### 2.4 후처리
- `[P0]` 영상 + 음성 무손실 병합(remux)
- `[P1]` 자막 다운로드(언어 선택) / 파일 분리 저장 / 영상에 임베드
- `[P1]` 썸네일 임베드, 메타데이터(제목/업로더/업로드일) 태깅
- `[P1]` 오디오 전용 추출(m4a/opus 무손실, mp3 변환)
- `[P2]` 챕터 임베드, SponsorBlock 구간 제거

### 2.5 설정/파일
- `[P0]` 저장 폴더 지정
- `[P0]` 파일명 템플릿(기본 `%(title)s [%(id)s].%(ext)s`), 파일시스템 금지문자 자동 치환
- `[P0]` 동일 파일 존재 시 동작(건너뛰기/번호 붙이기/덮어쓰기)
- `[P1]` 임시 폴더 경로 지정
- `[P1]` 브라우저 쿠키 임포트(연령 제한 영상 등)

## 3. 비기능 요구사항

| 항목 | 기준 |
| --- | --- |
| 성능 | 1Gbps 회선에서 10분 4K 영상 5분 이내 완료 |
| 메모리 | 유휴 200MB 이하, 다운로드 중 500MB 이하 |
| 응답성 | 다운로드 중에도 UI 프리징 없음(모든 I/O는 워커 스레드/프로세스) |
| 실행 | 별도 설치 없이 실행(ffmpeg 번들) |
| 플랫폼 | Windows 10+, macOS 12+, Ubuntu 22.04+ |
| 오류 처리 | 모든 실패는 원인 + 다음 행동을 함께 제시 (예: "4K 포맷이 없습니다. 이 영상의 최고 화질은 1080p입니다.") |
| 개인정보 | 시청 이력·쿠키·URL을 외부로 전송하지 않음. 텔레메트리 없음 |
| 로그 | 로컬 회전 로그, 문제 신고용 "로그 내보내기" 버튼 |

## 4. 제약 및 전제

- DRM 보호 콘텐츠는 지원하지 않음(감지 시 명확히 거절)
- YouTube 사양 변경에 따라 특정 포맷이 일시적으로 불가능할 수 있음 → 앱은 이를 장애가 아닌 "현재 제공되지 않음"으로 안내
- 라이브 스트림 진행 중 다운로드는 `[P2]`
